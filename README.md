# Auto Cards — учёт авто

Локальное веб-приложение для учёта закупки/продажи б/у автомобилей (Differenzbesteuerung, §25a UStG).
Next.js (App Router) + TypeScript + Tailwind + Prisma/SQLite. Однопользовательское, без авторизации, всё хранится локально.

## Запуск

```bash
npm install
npm run dev
```

Открыть [http://localhost:3000](http://localhost:3000).

При первом запуске база `prisma/dev.db` уже создана и миграции применены (`npx prisma migrate dev` уже выполнялся).
Если нужно пересоздать базу с нуля — удалите `prisma/dev.db` и выполните:

```bash
npx prisma migrate dev
```

## Структура

- `prisma/schema.prisma` — модели `Car`, `Expense`, `Attachment`.
- `lib/finance.ts` — формулы прибыли (маржинальное налогообложение, налог на прибыль).
- `app/` — страницы (список машин, карточка машины, отчёт за месяц) и API routes (`app/api/**`).
- `components/` — форма машины, таблица расходов, drag-and-drop вложений, панель финансов.
- `storage/uploads/<carId>/` — файлы вложений (сканы техпаспорта, счета). В БД хранятся только пути/метаданные.

## Распознавание техпаспорта (опционально)

Кнопка «Распознать данные» на карточке машины отправляет загруженный скан Zulassungsbescheinigung Teil I
в Anthropic API (модель с vision) и подставляет извлечённые поля в форму для проверки перед сохранением.

Чтобы включить — впишите ключ в `.env`:

```
ANTHROPIC_API_KEY=sk-ant-...
```

Без ключа кнопка просто вернёт понятную ошибку — остальной функционал работает как обычно.

## Формулы (Differenzbesteuerung)

Считаются live на карточке машины при любом изменении цены продажи или списка расходов:

```
Маржа = Продажная цена − Закупочная цена
НДС с маржи = Маржа × 19/119                (0, если Маржа ≤ 0)
Чистая маржа после НДС = Маржа × 100/119
Прибыль до налога = Чистая маржа после НДС − Итого доп. расходы + Входящий НДС
Подоходный налог = Прибыль до налога × 0.3  (0, если ≤ 0)
Прибыль после налогов = Прибыль до налога × 0.7 (или как есть, если ≤ 0)
Итог на руки = Прибыль после налогов + Обслуживание (чистыми) − Неофициальные расходы
```

Расходы с пометкой «Приват» (мимо кассы) не участвуют в базе НДС/налога на прибыль,
а вычитаются только из «Итог на руки».
